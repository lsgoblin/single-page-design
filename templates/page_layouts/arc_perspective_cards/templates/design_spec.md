# 弧形轨道透视卡片 — Layout Design Specification

## IV. Signature Design Elements

- 先确定一条从左下前景通向右上远景的视觉路径，再沿路径安放五张独立图片。缩放、遮挡、轻微倾斜共同表达纵深；不要把五张等大的图片排成网格，也不要仅通过旋转图片模拟远近。
- 整页场景作为背景，左上是短主标题，左下最大卡片是视觉入口，右上最小卡片是延伸终点。右下保留连续的说明区，包含独立徽章、主题名、中文副题、属性短句和两行说明。说明区不额外套底板。
- 五张卡片从近到远编号为 `card-1` 至 `card-5`，宽度约为 `592 / 452 / 324.8 / 236 / 174.4`，相邻宽度比约为 `0.73–0.77`。卡片中心逐级向右上移动，保留自然重叠；后方卡片的主要人物或内容焦点必须从前方卡片右侧露出。
- 轨道是一条有面积的弧形带，位于背景之后、所有卡片之前。近端宽、远端窄，下缘绕开右下说明区；原生自由曲线和渐变分别可编辑。可采用 SmartArt「降序流程」拆组后保留弧形箭头的办法搭建，也可直接使用下述贝塞尔路径；样张实际使用后者。
- 图层顺序固定为公共底色、背景图片、弧形轨道、最远卡片到最近卡片、徽章与文字。轨道、卡片和文字都保留在 Slide 上；Master 仅提供底色，不能把轨道下沉到背景图片之后。
- 图片用圆角矩形的图片填充承载，叠加轻量边缘、统一光照、原生右透视与短倒影。倒影贴住卡片底边，强度和面积低于主体；背景的纹理、卡片的薄边和倒影提供材质，不再添加装饰性小卡片。
- 深色场景与金色轨道是本次样张的示例外观，字体、题材、徽章和色值不构成下游身份锁。复用到产品、团队或里程碑时，更换完整的图片组和说明内容，同时保持远近关系与留白结构。
- 本包图片来自用户提供的内部学习素材，仅用于本地样张。不得把它们解释为通用授权素材；复用到其他作品时采用用户自己的图片。模板原型中的可替换字段不绑定《权力的游戏》文案。

## VII. Placeholder Overrides

### 轨道与卡片的复用参数

- 轨道在本画布中的路径为 `M 0 664 C 288 280 864 16 1280 70.4 L 1280 116 C 904 264 696 376 528 720 L 0 720 Z`。单独调整上下两条曲线以改变带宽；近端可以触及页面下边，右下说明区保持开放。
- 样张使用的原生三维设置：`msoCameraPerspectiveRight = 50`，在该预设基础上把 `ThreeD.RotationX` 调为 `10°`，形状平面旋转为 `355.5°`（即 `-4.5°`）；圆角调整值 `0.12`。只使用默认预设时，上边缘会明显向右下倾斜，因此需要轻微回转，使卡片整体沿轨道向右上延伸。
- 成品源尺寸 `1600 × 900` 对应 PowerPoint `1200 × 675 pt`。样张参数为厚度 `1.875 pt`、边线 `1.65 pt` 且透明度 `20%`、材质 `msoMaterialMatte = 1`、光照 `msoLightRigContrasting = 18`、倒影 `Type = 1`、透明度 `0.65`、大小 `28`、模糊 `1`、偏移 `1`。迁移到 `1280 × 720` 时，点数表示的长度乘 `0.8`；角度、比例、透明度不变。
- 示例轨道渐变从暗金到浅金，透明度约 `30%–45%`，只承担路径与承托作用。图像整体偏亮时降低轨道亮度；底色与轨道的具体色值按当前项目统一。
- 先摆放五张图再检查主体遮挡。样张第三张卡片从原始 `x=743` 调整到 `x=790`，使人物面部露出第二张卡片右侧；复用时应检查焦点位置，而不是照抄这个修正数值。

### SVG 原型与原生样张的边界

- `01_toc.svg` 是结构化槽位原型，使用独立原图、圆角裁切和平面微旋转表达位置关系，便于模板安装和内容替换。它没有宣称 SVG 能编码 PowerPoint 原生三维相机。
- SVG 原型不包含三维投影和倒影。完成内容替换后，以原生图片填充圆角矩形重新应用上述三维与倒影参数；不能把二维原型直接导出就称为原生三维成品，也不要将图片和文字整体栅格化。
- 精确三维效果以 `references/page_layouts/arc_perspective_cards/sample.pptx` 为准。样张含5张原生三维图片填充形状、原生倒影、独立轨道与可编辑文字，可以复制卡片后替换图片填充；SVG 原型的结构化 Master/Layout 是新建的复用约定，不是从样张恢复出的原生结构。
- 单页样张不包含滚动演示动画。需要 Morph 时，先复制出具有明确卡片位置变化的第二状态，统一对应对象名称，再添加平滑切换；只给一个静态页面添加转场不能展示卡片流转。

### 检查顺序

1. 核对五张图的近大远小关系和从远到近的绘制顺序。
2. 检查所有主要人物或图像焦点，尤其是中间卡片，是否被前景卡片遮住。
3. 检查轨道位于所有卡片后方，倒影没有压过主体，右下说明区没有被轨道或图片侵占。
4. 在 PowerPoint 实际渲染中检查三维边缘、倒影和裁切，再检查标题、主题名和两行说明是否溢出。结构检查通过不等于三维画面已经正确。
