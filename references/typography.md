# 字体与字号规范

图片排版只用一个 **4 级字阶**；默认 2 类字体（宋 / 黑二选一 + 等宽），用户可点名覆盖。

字阶数据：[type_hierarchy.json](type_hierarchy.json)。字体池：[typography_index.json](typography_index.json)。

## 默认 4 级

| 层级 | 字号 | 字重 | 行高 |
| --- | ---: | --- | ---: |
| 标题 | 100% | 600 | 1.3 |
| 正文 | 40% | 400 | 1.3 |
| 标注 | 32% | 500 | 1.3 |
| 脚注 | 20% | 300 | 1.3 |

- 先定标题实际字号，其余按百分比换算；百分比与 px 同时写。
- 用户说「弱一点」→ 正文 55% / 标注 38% / 脚注 25%。
- 未选层级直接删掉，不占位。

## 默认字体

| 组 | 默认家族 | 回退 | 用途 |
| --- | --- | --- | --- |
| **宋** | 思源宋体 | Noto Serif SC / SimSun | 插画、纸感、通用 |
| **黑** | 思源黑体 | Noto Sans SC / Microsoft YaHei | 照片、现代、正文 |
| **等宽** | Consolas | Courier New | 数字、英文、标注 |

- 默认只读这 3 组；用户点名时从 [字体池](typography_index.json) 的 23 款里选。
- 可选：明朝、仿宋、清刻本；瘦金 / 兰亭只上标题，其余层级回退思源宋体。
- 用户给未登记的本机字体名时，先确认安装并实排；缺字回退思源宋体。
- 未安装按 `stack` 回退；缺字回退思源宋体，并在说明里注明。
- 扩展字库上正文前必须实排；`coverage_ratio` 低于 0.95 的只上标题 / 短句 / 数字；`box_risk` 出现方框就换。
- 用户指定字体优先于默认宋 / 黑，但不得违反「书法只上标题」。

## 输出

固定 3 行：

```text
版式：纵向诗式
配色：米白 + 墨蓝（#1E4E63）
字体：思源宋体 → Noto Serif SC / 等宽 Consolas
```

只要用户不点名，色卡和字体都不问；默认取图配色、按图片类型选宋或黑。
