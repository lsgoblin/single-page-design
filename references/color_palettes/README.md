# 共用配色资源

用于单页 PPT-layout、图片改造与图片排版的共用配色，共 56 组（P01–P56）、280 个色位。它们与版式、图片风格独立组合，不新增制作模式。

## 发现与读取

从 `templates/color_palettes/color_palettes_index.json` 查看编号与五色组合，再读取选中条目的 `template` 和 `reference`。这些索引路径相对技能根目录；`sample.json` 的 `preview` 相对该样张目录。整体预览为同目录的 `overview.svg`。只加载选中的配色详情。

每组 `palette.json` 提供 `id`、`kind: color-palette`、`color_space: sRGB`、`applies_to` 和按原图从左到右排列的五个 `colors`。色位顺序不预设背景、标题等语义角色。每色保存正式采用的 `hex` / `rgb`，以及 `label_hex`、`sampled_hex` / `sampled_rgb`、`method` 和 `note`，便于追溯取值依据。

## 应用

- 用户指定的品牌色和当前任务要求优先。用户选定配色时按其编号读取；用户允许自行设计且未限定用色时，可从库中选择适合内容的配色，并说明所用编号。保留原配色的任务不自动套用资源库。
- PPT：在原策划与设计规格阶段记录配色编号、实际色值及背景、主文字、辅助文字、强调色的映射，沿用原确认节点。将颜色应用到可编辑文本、形状、填充与线条，保留图层和模板结构。不同页元素按对比和视觉权重分配颜色，不必用满五色；需要中性色或派生色时记录其实际值及用途。
- 图片改造：将所选色值和用途写入任务提示词，区分主体、背景与文字用色。图像生成可能产生近似色；需要准确 HEX 的文字或色块采用后期排版。严格保留原片时只给外围排版或独立面板用色，未经允许不调整原片肤色、产品色或整片色调。
- 图片排版：默认自动取色；用户点名 `色卡 P01` 或 HEX 时才读色卡，保留编号与实际色值，映射到背景、文字和强调色；不改变版式与字阶。
- 完成后检查实际画面的文字/背景对比与信息区分。配色本身不保证任意组合可读；需要调整颜色时遵循用户要求并记录变化。仅选择配色不改变模板或图片风格，也不触发重做整个作品。

## 来源与例外

本库采用已在 `drafts` 核对的色值，正式数据及预览均已随包保存。原图文件名、SHA-256 和可见署名保存在样张记录中，仅用于溯源，运行不依赖工作目录或原图。

主色值优先取原图 HEX 标注；像素采样是 JPG 解码 RGB 的近似值。P44 第 3 色的原标注重复为 `#E3E2D9`，与粉色色块不符，因此正式采用采样值 `#DEB9C1`；两个值均保留。P18、P41、P46 中的明显标注/像素差异也保留备注。RGB 按屏幕 sRGB 使用，不提供未经色彩管理转换的印刷 CMYK。

## 维护

新增配色保留既有编号，使用新 ID；定义置于 `templates/color_palettes/<id>/palette.json`，对应样张和来源说明置于 `references/color_palettes/<id>/`，更新索引和整体预览。校验 HEX/RGB 一致、ID 对应及包内相对引用。任务中的临时配色放在任务工作区，只有用户要求入库时才登记。
