# 图片排版模式

以用户图片（或画面描述）为内容来源，先定母版式，再按 8 个维度逐项选型，输出方案与字体层级，最后接 ASCII 预览、可执行清单和提示词/成图。用户说「图片排版」「图文排版」时进入本模式。

与其他模式的分工：

- **单页 PPT-layout**：交付可编辑 PPT，按原 PPT 生成流程执行。
- **图片改造**：套用已注册的视觉风格改造图片。
- **图片排版**：不套风格模板，按母版式和 8 维选项组合版式；交付图片方案，要成图时再排版或生成；不产出可交互网页。

## 0. 内容来源（开始前必选）

**铁律：选完模式，第一句必须问内容来源。不问 = 流程错误，重来。**

| 来源 | 用户给什么 | 我读什么 | 我产出什么 |
| --- | --- | --- | --- |
| **A · 本地素材** | 图/视频截帧文件 + 图片描述 + 文字素材 | **真实像素**：明暗、主色、饱和度、主体形状与位置 | 动态选型有据可依，直接出图 |
| **B · 自定义描述** | 一段画面描述（不给图） | 只有文字，颜色与色调靠描述推断 | ① 画面提示词 ② 版式方案 ③ 需要成图时用程序化画面替代 |

问了「本地素材」之后，**必须再问一次：上传新素材，还是用已有的？** 不许默认沿用上一张。

**素材缓存上限：3 张。**

- 只记得最近上传的 3 张，第 4 张进来就把最旧的踢掉；
- 不得主动引用更早的素材（除非用户点名要它）；
- 提问时最多列出这 3 张，不翻旧账。

两条路的差别在「动态选型的可靠度」：

- 本地素材：色彩、裁切、信息模块都能按真实画面判，规则里的「匹配原图明暗 / 主色 / 饱和度」是真的能做到；
- 自定义描述：没有像素，只能按描述里的词推断，推断出来的色值要等成图后才能校准。

**B 的边界**：交付是「画面提示词 + 版式方案」。要真图，拿提示词去生成，生完把图放回同一套版式，不用重排。没有可用图像能力时说明交付到提示词，不虚报已生成图片。

口令：`本地素材` / `自定义描述`。

## 1. 母版式（先定，不在 8 维内）

纵向诗式排版 / 环形焦点排版

先定母版式：用户指定则从其指定；未指定时按主体与信息量建议一个并说明理由。母版式确定后再进入 8 维，不能边选维度边换母版式。

母版式锁定的骨架项（网格 / 轴线、留白、主图位置、图文分组、动线、阅读顺序）在同一母版式的连续任务中保持一致，不因单张图改动；换母版式必须显式说明。

母版式已有定义时从其定义。没有既有定义时，用下表把同名骨架落成选项开工：

| 母版式 | 默认骨架 | 适合 |
| --- | --- | --- |
| **纵向诗式排版** | 垂直主轴、顶部大留白、图文上下分组、垂直诗式自上而下、低密度极简 | 单主体、短文案、安静叙事 |
| **环形焦点排版** | 同心圆环形网格、环绕留白、图片居中、文字环绕图片、环形顺时针发散、环形中心焦点 | 单主体、标注多、图鉴式说明 |

默认骨架只用于起步，不新增选项；各项仍取自下面 8 维的题干列表。

## 2. 八维选型

**规则**：每项为选择题，只从给定选项里挑，不自创新词。标注【单选】【多选】。

**固定顺序**：布局 → 结构 → 导航 → 视觉基调 → 文字排版 → 色彩 → 组件 → 可读性校验。

### 2.1 布局

- 【单选】画布比例：1:1 正方形、3:4 竖版、4:3 横版、16:9 宽屏、A4 竖版、A4 横版、2:1 超宽、自定义
- 【单选】网格/轴线系统：无网格自由排布、单栏对称网格、不对称网格、黄金分割锚点、垂直主轴、水平主轴、十字焦点、同心圆环形网格、对角线轴线
- 【单选】留白策略：顶部大留白、底部大留白、双侧均衡留白、左侧宽留白、右侧宽留白、环绕留白、紧凑少留白、均衡呼吸留白
- 【单选】主图位置：居中、偏上、偏下、靠左、靠右、对角线锚点、贴边出血
- 【单选】主图裁切形式：原始矩形、圆角矩形、圆形裁切、异形蒙版裁切、局部裁切、完整保留原图
- 【单选】图文面积配比：图70%｜文字20%｜留白10%、图55%｜文字30%｜留白15%、图40%｜文字45%｜留白15%、图30%｜文字35%｜留白35%、图20%｜文字50%｜留白30%
- 【单选】视觉重心：重心居中、重心上移、重心下沉、重心偏左、重心偏右、对角线平衡

### 2.2 结构

- 【单选】信息优先级模式：单核心强聚焦、主次双焦点、多标签并列、递进叙事型、注解图鉴型
- 【单选】图文模块分组形式：图文上下分组、图文左右分组、文字环绕图片、文字叠于图上、文字穿插咬合、分散锚点分组
- 【单选】阅读逻辑顺序：自上而下线性阅读、自中心向外发散、从左到右阅读、沿弧形顺时针阅读、编号跳转阅读
- 【单选】信息密度：低密度极简、中等舒适密度、高密度图鉴标注、高密度学术标注
- 【多选】包含的信息模块：主标题、副标题、英文标注、描述正文、关键词标签、参数标注、脚注来源备注

### 2.3 导航

- 【单选】主视觉焦点类型：图片为唯一焦点、标题为焦点、环形中心焦点、多点锚点引导
- 【单选】动线类型：垂直诗式自上而下、水平横向流动、环形顺时针发散、对角线斜向动线
- 【多选】视线引导载体：无显性引导、细实线引导线、虚线引线、箭头引导、序号编号、刻度标记、圆点锚点、弧形轨道
- 【多选】焦点强化方式：大小对比、色彩强调、框选容器、线条圈定、位置优先

### 2.4 视觉基调

- 【单选】版式气质：克制诗感、清冷学术、简约图鉴、柔和文艺、精密理性、轻潮拼贴、极简高级、沉静叙事
- 【单选】背景基底：纯白底色、纯色哑光底、低饱和渐变底、纸感细肌理底、原图直接做底、半透明蒙层底
- 【单选】光影氛围：平光无阴影、轻微软投影、内发光柔边、压暗蒙版、局部提亮、无特效
- 【单选】质感倾向：平面扁平感、纸本印刷感、精密线稿感、柔和摄影感

### 2.5 文字排版

- 【单选】文字对齐方式：左对齐、居中对齐、右对齐、竖排右读、竖排左读、弧形内侧绕排、弧形外侧绕排
- 【单选】字重选择：粗体、半粗、常规、轻量、超细
- 【单选】字号落差策略：大落差强对比、中等落差、弱对比柔和
- 【单选】行距字距：紧凑、标准、宽松舒展、极宽松诗化间距
- 【单选】文字摆放区域：图片上方、图片下方、图片左侧、图片右侧、叠图上（带蒙版）、图片外围环形排布
- 【单选】字体家族：思源宋体、思源黑体、明朝体（Mincho）、Helvetica、Noto Serif、Noto Sans、仿宋、清刻本宋体、瘦金体、兰亭行书、等宽等线（Consolas 风格）；也可从扩展字库的 12 款本机字体里选
- 【多选】文字分层：主标题、副标题、正文描述、关键词标签、脚注注释

字体选用、覆盖率限制与回退规则见 [字体与字号规范](typography.md)；不要在方案里临时加未登记的字体。

### 2.6 色彩

- 【单选】基底底色：米白、纯白、浅灰、炭灰、炭黑、雾蓝、墨绿、低饱和咖色
- 【单选】文本主色：炭黑、深灰、浅灰、白色（深色底）、低饱和主题色
- 【单选】线条装饰色：同文本色、金色细线、银灰、低饱和强调色
- 【单选】配色模式：黑白灰单色、双色低饱和、三色克制配色、同色系渐变
- 【单选】对比度策略：高对比清晰可读、中对比柔和、低对比氛围感（仅大标题）
- 【多选·最多 1 个】强调色：暗红、墨蓝、苔绿、砖橙

需要具体色值时，按 [共用配色说明](color-palette.md) 从 P01–P56 选，保留编号与实际 HEX；配色不改变本维度的选项。

### 2.7 组件

- 【单选】图片容器：无容器直接放置、圆角卡片容器、细描边边框、圆形底盘、半透明底色卡片
- 【单选】文字承载组件：无底色裸文字、单行胶囊标签、文本色块条、半透明悬浮块
- 【单选】分割元件：无分割、细横线、细竖线、圆弧分割线、点状虚线
- 【多选】引导元件：直线引线、弧形引线、空心圆点、实心锚点、刻度短线、编号圈标
- 【多选】装饰元件：细圆环、同心环线、极小图标、短刻度

### 2.8 可读性校验

- 【多选】当前存在哪些可读性风险：无风险、文字叠加对比度不足、文字遮挡主体、信息拥挤留白不足、主次层级模糊、引导线交叉混乱、注释字号过小、画面重心失衡

## 3. 选型判据（严格遵守）

选型分三类，另加一条硬性底线，不要混：

### A. 固定范式项 —— 跟随母版式，不随意改

纵向诗式排版 / 环形焦点排版一经选定，其骨架项照搬，不因单张图改动。

### B. 动态灵活项 —— 必须看图和素材，逐张判

动态项不只给结论：每条用一句话说明依据，例如「原片整体偏暗、主色是墨绿，所以基底选炭黑、强调色选苔绿」。

| 维度 | 判据 |
| --- | --- |
| **色彩全部题干**（基底底色 / 文本主色 / 线条装饰色 / 配色模式 / 对比度策略 / 强调色） | 匹配原图明暗、主色调、饱和度；画面色彩繁杂时优先「黑白灰单色」，避免色彩打架；底色与文字色必须自动保证可读；强调色优先贴合画面已有色相 |
| **结构-包含的信息模块** | 按需勾选：用户给了哪类文字就勾哪项，没有就不勾 |
| **组件-引导元件 / 装饰元件** | 有多处标注需求才用引线、锚点、刻度、圆环；纯配图不选。环形版式优先弧形引线 + 圆环；诗式默认精简装饰 |
| **布局-主图裁切形式 / 图文面积配比**、**视觉基调-版式气质** | 以母版式默认基线为准，按主体形状、信息量酌情调整 |

### C. 后置风险校验项

**可读性校验**：整套选项确定之后再推导，评估方案自带风险，自动勾选。不能提前固定。

### D. 硬性底线

所有选项只能从题干列表里挑，禁止自创词汇；要自定义就用选项里的【自定义】。

## 4. 输出顺序

1. 先写母版式：纵向诗式排版 / 环形焦点排版
2. 严格按 8 大维度顺序逐条输出：`维度名-题干：选定选项`
3. 附**字体层级规范**：字体家族、字号落差、行距倍数与七级层级，按 [字体与字号规范](typography.md) 组装
4. ASCII 预览示意图：用等宽字符标出图、文、留白的相对位置与比例
5. 可执行排版清单：位置、尺寸、字号、色值、层级逐条落成可执行指令
6. 绘图提示词：画面、构图、材质、光线、色彩与排版结构；关键文字交给原生排版，避免生成错字

只能选给定选项，不自创描述词。方案未勾选的文字层级直接删掉，不占位。

## 5. 成图与交付

- **只要方案**：按第 4 节在聊天里给出 1–6 项，不建方案 `.md` 文件。
- **要成图**：优先用 SVG/HTML 画布做原生排版，用户图片作为素材放入；关键文字不要交给图像模型生成。需要重绘画面时，按第 6 项提示词生成，再把图放回同一套版式。
- **交付**：成图给预览 PNG 与可编辑源（SVG 或等价工作文件）；说明哪些元素是位图、哪些文字是原生排版。
- **不产出**：可交互网页、可编辑 PPT 原生页。需要网页属于其他范围；需要可编辑 PPT 时改走 [单页 PPT-layout 流程](single-page.md)。
- 交付前检查实际画面：文字是否压到主体、对比度是否足够、引线是否交叉、注释字号是否过小、留白是否被挤掉。
