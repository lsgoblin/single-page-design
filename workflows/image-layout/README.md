# 图片排版模式

一张图 + 一句话 → 直接出图。默认不问风格，只问缺失的文案；用户可点名色卡和字体。

## 输入

- **必给**：图片（或画面描述）。
- **可选**：一句话文案、用途（海报 / 封面 / 图鉴）、`色卡 P01`、`字体 黑体`、`黑白`、`全出血`、`环形`、`竖排`。

例：`图片排版：苍蓝一闪，光在指尖炸开。色卡 P01，字体 黑体。` 只发图 + `图片排版` 也能跑。

缺图片才问图片；缺文案只问一次，用户不给就只做图，不编造标题。风格、颜色、字体、版式默认不问。

## 三套默认版式

| 版式 | 何时用 | 骨架 |
| --- | --- | --- |
| **纵向诗式（默认）** | 大多数图；没说用途 | 3:4，图上文下，顶部留白，米白 / 墨色 |
| **全出血** | 宽图、暗图、只有一句标题 | 图做底，压暗蒙版，文字叠图 |
| **左图右文** | 宽图、主体偏一侧、文案多于一行 | 左右分栏，图 40–55%，文字右栏 |

- 宽图默认仍走纵向诗式：图按原比例做成上方图版，不硬裁。
- `环形`（仅点名）：同心圆网格、图片居中、文字绕图、顺时针动线。
- `环形 / 竖排 / 黑白 / 全出血 / 左图右文` 是关键词覆盖，不提问；`竖排` 只用于纵向诗式。
- 预设锁骨架：网格、留白、主图位置、图文分组、动线不随单图改。

## 读图规则

| 读什么 | 怎么判 |
| --- | --- |
| 比例 | 竖图 → 上图下文；宽图 → 上图下文 / 全出血 / 左图右文；方图 → 居中 |
| 主体 | 偏一侧 → 分栏；居中 → 上下 |
| 明暗 | 亮图 → 米白底 + 墨字；暗图 → 墨底 + 纸字 |
| 主色 | 只做一条强调线或一个点，不做正文色 |
| 密度 | 画面杂 → 标题 + 一行 + 页脚；画面简 → 加 3 个关键词 |
| 类型 | 插画 / 动画 → 宋体；照片 / 现代 → 黑体 |

对比度自动 ≥4.5:1（≥24px 可 3:1）。不问「配色模式」。

## 字阶

| 层级 | 字号 | 字重 | 行高 |
| --- | ---: | --- | ---: |
| 标题 | 100% | 600 | 1.3 |
| 正文 | 40% | 400 | 1.3 |
| 标注 | 32% | 500 | 1.3 |
| 脚注 | 20% | 300 | 1.3 |

- 默认 2 类：宋体（插画 / 纸感）或黑体（照片 / 现代）二选一，加等宽（数字 / 英文）。
- 字体细节与回退见 [字体与字号规范](typography.md)；用户可点名字体。
- 未选层级直接删掉；标题字号先定，其余按比例换算。
- 用户说「弱一点」→ 正文 55% / 标注 38% / 脚注 25%，不写入数据。

## 可选覆盖

| 用户说 | 覆盖 |
| --- | --- |
| `色卡 P01` / 色卡图 / `#RRGGBB` / `黑白` | 配色：P01–P56 查 [色卡库](../color-palette.md)；色卡图读 3–5 个主色；保留编号与 HEX |
| `字体 宋体/黑体/明朝/仿宋/清刻本/瘦金/兰亭/等宽`，或其他字体池家族名 / 本机字体名 | 字体：从 [字体池](../../references/typography_index.json) 选；书法只上标题；未安装按 stack 回退 |
| `环形` / `全出血` / `左图右文` / `竖排` | 版式：只改这一项，其他默认不动 |

覆盖只改对应项；用户没说就不问。色卡和字体是用户的选择，不是必答题。

## 输出

1. 成图 PNG + 可编辑源（HTML 或 SVG）。
2. 3 行说明：`版式 / 配色 / 字体`。
3. 缺文案只问一次；不问风格、颜色、字体、版式。
4. 用户主动要提示词时，给一段短提示词；不给 8 维方案、不给 ASCII，除非用户要。

## 内部提示词

```text
读图定版式：竖图→上图下文；宽图→上图下文/全出血/左图右文；方图→居中。
取色：亮底墨字，暗底纸字；主色只做强调线；用户点名色卡才覆盖。
排字：100/40/32/20，行高 1.3，宋体或黑体 + 等宽；用户点名字体才覆盖。
缺文案只问一次；不问风格；出 PNG + 3 行说明。
```
