# 爱马仕橙 · 魔力黑 · 白粉

奶白底 + 一块响橙 + 炭黑。橙色面积决定气质：小面积是"包装"，大面积是"宣言"。

- **id**：`hermes-orange`
- **底色**：light
- **气质**：明快、果断、商业、有冲击力
- **比例**：白粉 50 / 魔力黑 30 / 爱马仕橙 20
- **强调色**：**仅色块/填充**，不作文字（浅底仅 2.14:1）；橙块上请配 `body_text`（7.45:1）
- **适配风格**：✓✓ `brutalist` `swiss-minimal` · ✓ `editorial` `data-journalism` `photo-editorial` `vintage-poster` `memphis` `paper-cut`
- **不适用**：需要安静、学术、奢华克制的材料；需要长期阅读的长文档
- **禁忌**：橙上放白字（2.36:1）；橙做正文或大段文字底；橙与炭黑等面积（会像警示带）
- **来源**：用户提供的配色灵感图「爱马仕橙·魔力黑·白粉」（本会话附件），图上 HEX 为 `#ff8a00` `#373A3E` `#fff2df`

## 2. 怎么用

- **封面**：白粉满版，炭黑大字，橙作一整块底（其上放深色标题）或一条贯穿页面的粗色带。
- **章节页**：炭黑满版反白，橙作序号或一条底边。
- **正文页**：白粉底、炭黑正文；橙只出现在关键数据、页码块、动作提示上，面积不超过单页 20%。
- **数据页**：炭黑主系列，`secondary_accent` 对比系列，橙只标"要被看见的那一个值"；橙块上的数字用深色。

## 3. 边界

- 橙 2.14:1，只能当色块；一旦当文字就是典型的"好看但读不清"。
- 橙面积超过 20% 后，气质从"高级包装"翻成"促销海报"，需要靠炭黑与留白压回来。
- 与 `sketch-notes`、`soft-rounded`、`ink-notes`、`ink-wash`、`pixel-art` 及全部深底风格不匹配。
