# 提香红 · 古驰绿 · 鸭卵青

复古绿调 + 一支暖橙。深绿承担权威与结构，橙只作强调——比例越克制越像"成书"，越铺越像促销。

- **id**：`titien-green`
- **底色**：light
- **气质**：复古、editorial、沉稳、有年代感
- **比例**：鸭卵青 55 / 古驰绿 30 / 提香红 15
- **强调色**：可作大字与色块；作正文小字不够（4.05:1），但其上可放白字（4.81:1）
- **适配风格**：✓✓ `editorial` `photo-editorial` `vintage-poster` · ✓ `data-journalism` `paper-cut` `brutalist` `swiss-minimal`
- **不适用**：需要现代科技感、需要冷感克制的材料
- **禁忌**：橙绿等面积并置（立刻变圣诞）；橙做长段落正文（4.05:1）；在浅绿底上再叠一层浅绿
- **来源**：用户提供的配色灵感图「提香红·古驰绿·鸭卵青」（本会话附件），图上 HEX 为 `#b05b24` `#1F4433` `#e4eee6`

## 2. 怎么用

- **封面**：鸭卵青满版，古驰绿写大标题，橙只出现在一个短标签或一条细横线。
- **章节页**：古驰绿满版反白，橙作序号或一条底边。
- **正文页**：浅青底 + 深绿正文结构，橙只标结论、风险与关键数字（可用橙块反白）。
- **数据页**：深绿主系列，`secondary_accent` 对比系列，橙只标异常值或目标线。

## 3. 边界

- 橙 4.05:1 卡在"够大字不够小字"的位置：**≥24px 或色块可以，正文不行**。
- 绿底上避免再用橙描边，两个饱和暖冷色相贴会产生边缘振动（视觉发颤）。
- 与 `memphis`、`zine`、`sketch-notes`、`pixel-art` 及全部深底风格不匹配。
