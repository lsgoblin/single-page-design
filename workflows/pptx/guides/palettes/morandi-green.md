# 不焦绿 · 莫兰迪绿

清新素雅的单色系。米色作纸场，深绿承担结构，浅绿作次要色块，最关键的一句用"再深一档的绿"。整套只有一个色相，靠明度分层说话。

- **id**：`morandi-green`
- **底色**：light
- **气质**：清新、素雅、自然、不焦躁
- **比例**：米色 55 / 白 20 / 主绿 20 / 浅绿 5
- **强调色**：可承担文字（浅底 5.79:1，由主色压深派生）
- **适配风格**：✓✓ `editorial` `photo-editorial` `ink-wash` · ✓ `swiss-minimal` `data-journalism` `paper-cut` `sketch-notes` `soft-rounded` `ink-notes`
- **不适用**：需要强对比与警示语义的材料；暗场、发布会、科技硬件内容
- **禁忌**：主绿 `#6B8957` 用于正文小字（浅底 3.49:1）；浅绿 `#A5C190` 用于任何文字；在同一页同时用三档绿做前景（层次会糊）
- **来源**：用户提供的配色灵感图「国家级美学配色 · 不焦绿」（本会话附件），4 个作者色 `#6B8957` `#A5C190` `#FAF2CB` `#FFFFFF`

## 2. 怎么用

- **封面**：米色满版，主绿写大标题（≥32px），浅绿作一条色块或图形，强调绿只用在一个词或一个数字上。
- **章节页**：主绿满版反白，浅绿作序号底块；一页只用一档绿做前景。
- **正文页**：米色或白底，正文用 `body_text`（近黑绿），小标题用强调绿；主绿只出现在大字与色块。
- **数据页**：主绿与浅绿作两条系列（深浅对比足够区分），网格用 `divider`；强调绿只标目标值或异常点。整套单色系，不需要第三支色。
- **"素雅"的边界**：一旦出现第二个色相（例如红黄点缀），这套就失去了莫兰迪气质。

## 3. 边界

- 主绿 3.49:1 是这套色的天然上限：**它能做标题和色块，不能做正文**。要更深的字，用 `body_text`。
- 浅绿 1.75:1 只适合填充；在米色上画细线几乎看不见，线条请用 `divider`。
- 投影环境偏暗时，把 background 换成 `secondary_bg`（白）提亮，其余不变。
