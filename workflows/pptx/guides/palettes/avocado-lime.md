# 牛油果绿 · 百草露 · 芡食白

冷灰底 + 一支响亮的绿。中性打底让绿色显得克制，绿色只做色块与标记，不承担文字。

- **id**：`avocado-lime`
- **底色**：light
- **气质**：清醒、现代、植物感、克制里的一个亮点
- **比例**：芡食白 55 / 百草露 30 / 牛油果绿 15
- **强调色**：**仅色块**，不作文字（浅底仅 2.12:1）；色块上请配 `body_text`（6.34:1）
- **适配风格**：✓✓ `swiss-minimal` `data-journalism` · ✓ `editorial` `photo-editorial` `brutalist` `paper-cut` `soft-rounded`
- **不适用**：需要暖意与怀旧感的材料；需要多色相并置的表达
- **禁忌**：牛油果绿上放白字（2.76:1）；把绿当正文或小标签；绿与灰等面积并置（会互相削弱）
- **来源**：用户提供的配色灵感图「牛油果绿·百草露·芡食白」（本会话附件），图上 HEX 为 `#7fa921` `#423F3D` `#e2e1e6`

## 2. 怎么用

- **封面**：芡食白满版，百草露写标题，牛油果绿作一条粗色带或一个大圆点。
- **章节页**：百草露满版反白（10.45:1），绿色只作序号底块。
- **正文页**：白底深灰字，绿色只出现在图示、标签底、关键标记上，不上文字。
- **数据页**：深灰为主系列，`secondary_accent` 为对比系列，绿色只标"这一根"的填充；网格用 `divider`。

## 3. 边界

- 这套色的亮度差已经足够，**不需要再加第二支绿**；加浅绿会让画面发灰。
- 绿色 2.12:1 注定只能做面，不能做字。需要"绿色文字"时用 primary 加粗，或用绿色色块 + 深字。
- 投影环境偏暗时，把背景换成 `secondary_bg` 之外的纯白可提亮，但绿色块会随之显得更亮，需重算面积。
